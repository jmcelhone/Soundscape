# How to Install and Use Soundscape

The live website can be accessed here: [soundscape.work](https://soundscape.work)

The website and geolocation features are compatible with the following browsers:
Confirmed Working
- Safari
- Firefox
    - base
    - Zen
- Google Chrome

Confirmed not Working
- OperaGX
