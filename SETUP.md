# How to Set Up and Deploy

## How to obtain source code
Navigate to our source repo on GitHub and navigate to releases. Clone the source repo or download the latest release (.zip) file and place in the desired location on your machine. Follow the setup and build instructions in [User Manual](User-Manual.md#set-up-environment).

## How to Deploy
For setting up the production environment refer to [Developer Docs](dev-docs.md#buildrelease-for-production). Choose your preferred hosting solution (cloud or self-hosted). We are currently using [Render](https://render.com).
